〇操作方法

頭・手足の操作：クリック＆ドラッグ


〇作品概要

2025年8月に開催された企業合同ゲームジャムにて制作した作品です。テーマである「社交ダンス」から「リフト」の動きに着目し、さらにアイスダンスの要素を組み合わせることでゲームとして表現しました。頭や手足をドラッグ操作で動かし、指定されたポーズを再現するミニゲームです。

〇制作で意識したこと

3日間という限られた開発期間のため、簡潔なゲーム性を目指しました。

また、初めて遊ぶ人でもルールをすぐ理解できるよう、分かりやすいUIや説明を意識して制作しました。

短期間でも完成度の高い作品にするため、遊びの分かりやすさと操作のしやすさを重視しました。
